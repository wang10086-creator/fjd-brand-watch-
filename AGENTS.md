# FJD brand monitor maintenance

Preserve existing browser manual search, cloud schedules, encrypted private data,
public cross-device reads, append-only report events, review history, and retired
report dates when changing features. Before edits, map affected dependencies and
data flows; record nontrivial decisions in docs/architecture-and-regression.md.
Use minimal compatible changes. Never infer trademark ownership from a language,
country, or spreadsheet tab. Source access failures are not evidence of removal.
After changes, run relevant tests, npm test, and the cloud Python tests; exercise
browser navigation and cloud/Notion integrations when touched. Add regression
cases for discovered bugs. Do not mark untested integrations as verified.
No secrets, raw webhook addresses, passwords, or private review notes in logs or
public output. Keep historic event checksums stable during display migrations.
