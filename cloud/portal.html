创建仅限本仓库的同步凭据 ↗
  1. 在 GitHub 页面确认 Resource owner 为 wang10086-creator。
  2. Repository access 选择 Only select repositories，勾选 fjd-brand-watch-（名称末尾有短横线）。
  3. 在 Permissions 中点击 Add permissions → Repository permissions，添加 Actions 和 Contents，两项均设为 Read and write；Metadata 保持默认。
  4. 点击 Generate token，复制生成的凭据，粘贴到下方“GitHub 同步凭据”。请勿发送到聊天。
  5. 上方输入你在 GitHub Secrets 保存的 MONITOR_CLOUD_PASSWORD，然后点击“验证上传与同步权限”。若忘记密码，请先说明情况，避免直接修改后无法解密已有台账。

云端归档与机器人设置（已配置时无需重做）

公开阅读与自动写入是两项权限。已发布的站点可直接访问；云端归档还需一个只连接到日报总页的 Notion 连接。

  1. 打开 Notion 连接设置，新建内部连接“丰疆日报归档”，选择日报所在工作空间，仅保留读取、插入、更新内容能力。复制内部连接密钥。
  2. 打开 日报总页，右上角“··· → 连接 → 添加连接”，选择“丰疆日报归档”。保留当前公开发布设置，并确认子页面也可公开阅读。
  3. 在 GitHub Repository secrets 添加 NOTION_TOKEN，值为刚复制的内部连接密钥。已有 MONITOR_CLOUD_PASSWORD 继续沿用。
  4. 在需要接收简报的飞书群内，打开“设置 → 群机器人 → 添加机器人 → 自定义机器人”，名称可设为“丰疆品牌监控”。将 webhook 保存到同一 GitHub 页面，名称为 FEISHU_BOT_WEBHOOK；如启用签名验证，再保存 FEISHU_BOT_SECRET。如启用关键词校验，请包含“丰疆品牌监控”。

密钥仅在 GitHub Secrets 中保存，不在聊天或公开页面填写。Notion 连接失败时，检索继续，待归档记录会保留；飞书只发送简报，不参与文档授权。
