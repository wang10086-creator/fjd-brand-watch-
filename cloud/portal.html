一次性配置

  1. 在飞书应用 用户身份权限开通 bitable:app（含编辑能力）。免审状态以你公司的后台提示为准。
  2. 打开 GitHub 受保护配置，点击“New repository secret”，确认位于 Repository secrets 栏目，添加 FEISHU_APP_SECRET：值来自飞书“凭证与基础信息”。再添加 MONITOR_CLOUD_PASSWORD：你自行设置至少 12 个字符的数据密码。添加完成后，两个名称应出现在 Repository secrets 列表中；不要添加到 Variables、Environment secrets 或其他仓库。密钥不在本页填写，不发到聊天。
  3. 群简报：在目标群添加“自定义机器人”，将 webhook 保存为 GitHub Secret FEISHU_BOT_WEBHOOK；若启用签名验证，将签名密钥保存为 FEISHU_BOT_SECRET。这两项可以稍后配置。
  4. 在下方输入同一个云端数据密码，启动“本人授权”；云端生成飞书官方确认链接后，在下方状态区域打开并确认。系统会检查目标表格访问和编辑能力，再建立日报结构。令牌自动续期，过期或被撤销时会提示重新授权。

目标：你提供的日报多维表格。同一天累计显示在“日报概览”，每次原始结果保存在“更新记录”；旧记录保留。
