# V2 线索复核优先级交付说明

## 规则及适用边界

来源为用户提供的《品牌监控线索优先级评估-V2.docx》，规则版本为
`V2.0-20261020`。高、中、低只表示安排人工复核的顺序；待评估是证据不足的临时状态。

| 等级 | 独立命中规则 |
|---|---|
| 高 | H1 品牌域名与相符产品类型；H2 品牌商品销售、报价或转售；H3 当前经营者的品牌／渠道身份声明 |
| 中 | M1 第三方配件或产品明确适配；M2 明确的合作、联名或集成关系；M3 品牌／产品为主体的资料、资讯或测评 |
| 低 | L1 有证据指向其他对象；L2 其他主题中的偶然提及；L3 完整有效核实范围内的稳定使用 |

`priority.js` 同时提供九项定义和评估函数，`priority-view.js` 直接复用这些定义。
匹配使用品牌档案别名、已知型号、域名、标题、摘要、已有正文、句内关系、否定／引用语境、
具体电商刊登入口和品牌参照图比对信息。兼容配件单独识别，不因“出售”一词就变成品牌原装商品。
同一线索保留全部有效命中，一般高优先于中、低；L3 完整覆盖时允许适用低优先级特例。

每次评估包含等级、规则编号及名称、来源及文本片段、理由、时间、规则版本与输入摘要。
重复检索不重复生成同一评估；实质证据变化后保留此前自动评估及证据，形成独立自动评估历史。

### 不能自动推断的情况

- 裸品牌词、通用型号、缺少主体关系的长段文字，可能仍为待评估；页面403或图片缺失不会被当作低优先级证据。
- 型号、行业及多语言关系存在歧义时，不臆造商品归属、合作关系或授权状态。当前规则是可追溯的文本关系和结构化证据判断，不等于通用语义理解；未覆盖的表达可由人工调整。
- H1 需要有依据的产品类型对应关系；无法从现有品牌上下文判断类型的域名，不直接升高。
- 纯图形线索仅在已有匹配参照标识及相应行为证据时参与评估，不靠相似度判断授权。
- 旧处理记录通常没有完整核实范围，不能仅凭结案或备注启用 L3。支持显式 `priorityVerification`：verified 状态、依据与核实时间、可选有效期、当前主体／站点／行为／使用范围、对应证据摘要；当前行为须全部被覆盖，证据未变且无矛盾。人工调低等级也不等于系统验证了 L3。

## 页面与操作

- 监控日报：当日新增／变化去重范围的当前优先级分布；卡片跳转保留日期、范围和等级；证据明细提供优先级筛选及颜色文字标签。
- 线索复核：在处理进度前增加五类卡片，保留优先级自身以外的有效筛选；增加等级下拉框、最近发现／等级正序／等级倒序。处理阶段仍是独立统计维度。
- 线索详情：独立的“优先级评估与调整”区域，显示生效等级、原自动等级、规则与证据、评估时间、人工及自动历史。“保存优先级”不提交处理表单，保留正在填写的处理意见。
- 人工调整：高、中、低需简要原因，恢复自动无需另填原因。依据变化时保留人工等级并提示复查；可以再次保存人工选择或恢复最新自动等级。
- CSV 增加生效等级、自动等级、规则编号及调整历史，旧列不删除。完整备份和 IndexedDB 继续保存全部字段。
- Notion、HTML 导出和飞书简报增加“当前优先级”汇总，原始新增／变化、处理进度、趋势、覆盖率、归档链的定义不变。

## 数据、独立保存及同步

在原线索上扩展 `priorityV2`，包含 `auto`、`manual`、`history`、`assessments`；不建立第二套线索库。
原 `risk/assess` 为历史报表及变化检测保留，新界面不会使用旧算法冒充 V2。

保存优先级仅更新这套字段及独立调整审计。不会调用 `recordReview/appendReview`，
不会修改 `reviewedAt`、处理意见、处理阶段、结案类型、轮次或核查事实。存储失败时撤回本次调整。

同一页面仍按原 URL 去重。再次检索、导入、私有／公开读取及多设备合并时，按调整事件 ID 合并历史；
以操作时间和稳定 ID 确定生效事件，较旧上传不能抹掉较新的调整。恢复自动也作为审计事件保存。

使用已有数据密码、仓库权限及加密通道，同步请求在原 `sync` 操作中增加可选的
`priorityUpdates`。云端只接收独立优先级记录，不模拟处理事件；服务器合并保持幂等。
旧完整台账迁移同样保留这些字段。没有浏览器同步凭据时先保存本机并明确提示待同步，
已有凭据时自动排队；只有云端读回确认后才清除待同步标记。

公开副本仅提供当前等级、标准规则摘要和非敏感调整元数据；不发布调整原因、原文内部评估证据、
完整自动历史或私有核实记录。匿名设备直接采用云端已评估结果，不用缩短的公开摘要覆盖完整自动依据。

日报优先级作为单独当前投影生成，不加入原始事件的 `cumulative` 或已保存报告快照。
历史日报明确标注“当前优先级”；旧不可变事件及校验值不回写。删除的12号日报不会恢复。
