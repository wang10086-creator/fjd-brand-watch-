# 线索复核：统一确认处理

## 本次修改

- 移除“仅保存核查事实”按钮；初核、IP复核、后续处置和已结案信息补充统一通过“确认处理”提交。
- “核查意见”改为“处理意见”；依据、轮次记录、事件时间线及相应 CSV 表头采用处理用语。阶段名称保持原样。
- “补充处理信息（可选）”保留折叠、填写和恢复能力。访问状态、图片比对、证据链接、持续复查及备注沿用原字段，随正式操作一起保存；折叠该区域不会漏存。
- 成功反馈说明当前阶段及本机保存结果，云端归档仍以实际同步回执为准。
- 已结案线索保留“重新打开”操作，必须填写原因并回到新一轮初核。补充处理说明不会覆盖原结案依据。
