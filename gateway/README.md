# Shared cloud connection

Deploy `gateway/Dockerfile`, start `node gateway/server.mjs`, mount an independent persistent volume at `/data`, health check `/health`. Use one replica. Run `npm ci --ignore-scripts` for local gateway development and tests; the Docker image installs the pinned production dependencies itself. The streaming validator uses BSD-3-Clause `stream-json` 1.9.1. The original GitHub Pages frontend remains in place. `cloud/service-config.json` identifies this project's Railway endpoint; it contains no secrets.

On the original workbench open `cloud/portal.html`, expand “首次管理员配置”. Choose an administrator username and a workbench password of at least 12 characters. Supply the existing cloud data password and repository owner's GitHub token (the original browser may supply already retained credentials). Setup verifies the owner and decrypts the existing dashboard. It neither rewrites the ledger nor creates a new cloud password. Never paste these credentials into chat.

The administrator then assigns ordinary member accounts. Members log in from any device without cloud passwords or GitHub credentials. Sessions last 30 days; logout, disabling an account or resetting its password revokes sessions. Private records remain subject to authenticated access. Pending local records must still be synchronized from the browser that holds them, and cloud acceptance must be confirmed separately.

Persist and back up `/data` securely, including its encryption key. The service holds connection configuration, accounts, sessions and idempotency receipts only, not a duplicate business ledger. Do not reset the volume to rotate credentials or resolve errors. Administrative credential rotation is not yet exposed in the UI; an expired backend token needs a controlled maintenance operation preserving the existing state. Do not publish the volume or logs containing its data. Railway usage may incur its normal service/storage charges.

The gateway authenticates AES-GCM before streaming the compressed JSON through a full validator. It caches the original compressed bytes and never materializes a whole dashboard or rewrites historical data. Validation has bounded time, depth and expanded-byte limits. Run `node --max-old-space-size=128 scripts/shared-gateway-large-check.mjs` for the isolated 512MiB synthetic-ledger regression (mock GitHub, temporary Unix socket/storage, no production writes).
