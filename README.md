# 丰疆中国与海外品牌监测 · 免费静态版

仓库根目录包含可直接部署的静态文件，无需构建、登录或服务器。GitHub Pages 分支 `main` 根目录托管。

## 使用

- **监控日报**：按北京时间每天一份累计报告；显示新增、变化、待核查、来源分布、复核进度和查询覆盖。证据明细默认折叠。
- **线索复核**：一个处理结论和对应依据；页面状态、图形比对为可选事实，不混同授权结论。
- **监控配置**：一个入口内维护品牌与参照图、市场平台、规则、连续执行及页面内周期与独立云端计划。
- **运行中心**：实际来源状态、查询日志、失败原因、Notion 自动归档与飞书群简报和本机 JSON 迁移。

自动与手动检索按同一个北京时间日期累计，规范化页面链接去重。检索后生成记录，不等待全部复核；待核查与已核查分开显示。每次检索、站点补查、复核产生不可变更新记录，Notion 同日子页面持续追加，不替换原报告。跨午夜任务归入开始日期；次日复核追加到次日。可下载当前累计图表与更新链的 HTML（打印 PDF）。优先级不等于侵权认定。日报指标与线索标题可直接打开对应复核范围。

数据保存在本机 IndexedDB，兼容 `fjd-watch-static-v2`；任务独立保存。现有线索、备注、图片与周期设置继续兼容。GitHub 加密云备份界面已移除；既有远端密文未删除。更换设备请用本机 JSON 备份迁移，公开日报不是完整任务数据库。

无密钥文字检索使用 Tavily 公共访问模式。将实际完全相同的索引请求合并，保留覆盖目标市场与语言。在全部 83 市场、84 平台、现有全部文字名称下，143,346 种组合对应 13,860 条不同请求，减少约 90.3% 重复；不代表已经执行这 13,860 条。各平台轮转，默认每次连续执行 60 条，可选 20/60/120/300；旧的 20 条选择保留。页面关闭、休眠或离线时不执行，每次到期按所设数量继续队列。逐条保存，可暂停后继续。立即更新从队首重查本次额度，不再受最近单条查询影响。

请求间隔 1.2 秒；短时 429 最多冷却重试两次，遵循 Retry-After（较长冷却直接保存进度并暂停）。临时网络/服务器错误重试一次，连续三项失败暂停；身份访问限制仍如实记录。免费通道可能限流，不保证全量或不失败。无命中会尝试简化品牌词补查；严格检查目标域名及正文/标题品牌文字，URL 文字单独出现不保留。

图片参照保留 Excel 70 组、123 张样式及官网图片；图片检索仍需人工在外部图片搜索提交，不声称有自动相似度能力。

## Notion 公开日报与飞书群简报

当前入口：[归档与推送设置](cloud/portal.html)。Notion 日报总页使用用户提供的公开站点；原飞书文档、多维表格授权与本机助手入口已从网站移除。旧适配器作为兼容源码保留，不再由当前网页或云端任务调用。

- `cloud/delivery.py` 使用 Notion REST 接口按日查找/创建子页，每次更新追加折叠记录。稳定记录校验支持响应丢失后的安全补同步，同一更新内容改变时停止覆盖。累计卡片更新不删除旧批次。
- 公开报告只包含统计及公开线索，不发送内部核查备注与授权证据。完整台账仍使用 AES-GCM 加密后放在 `data-cloud` 分支。
- `NOTION_TOKEN` 放在 GitHub Repository secrets，连接只授权到日报总页。公开发布由页面所有者管理；阅读公开站点无需登录，自动写入仍需要连接权限。
- 飞书自定义机器人只需 `FEISHU_BOT_WEBHOOK` 和可选 `FEISHU_BOT_SECRET`，不需要企业自建应用和文档权限。归档失败不阻断检索或摘要推送。群发送回执不明时不自动重发，防止刷屏。
- GitHub Actions 每天北京时间 08:00 起分批检索、10:30 简报，可能排队延迟；网页显示实际执行与写入回执。手动立即检索、补查和补同步继续支持。
- `MONITOR_CLOUD_PASSWORD` 沿用原数据密码。首次迁移保留原密文备份，用现有应用密钥解密旧台账后，改用数据密码保护新台账；当前执行不再要求飞书 OAuth。
- 网页自动提交本机增量需要当前会话的 GitHub Actions/Contents 执行权限；未配置时，本机记录保留，可在设置页生成加密迁移内容手动提交。
- 每个网站卡片使用紧凑按钮；仅实际请求的站点显示检索中，其余等待当前任务。站点补查最多 5 条，优先失败与未执行，不重置全局游标。

验证：`npm test`；`python -m unittest discover -s cloud -p 'test_*.py'`。

## 全球监控与图表日报

默认启用全部 104 类平台及 83 个市场。全球入口指公开索引范围，不等于当地交易或配送可用，也不代表原生 API 接通。每日自动查询最多 360 条，每批最多 60 条；未执行入口优先、失败冷却后补查、跨日续查；并非每天扫完全部关键词组合。单站补查仍最多 5 条。

日报优先展示新增、变化、优先核查、复核进度、七日趋势和网站覆盖；明细折叠。Notion 同时保留每次更新图表和当天最新概览。公开 PNG 仅使用汇总数字，不含内部备注；字体遵循附带 OFL 许可。图表生成失败时继续文字归档和群简报。

verify 执行 8 条真实查询、同步 Notion，并发送明确标记的测试群简报；测试回执独立于每日简报，不占用当日正式推送。
