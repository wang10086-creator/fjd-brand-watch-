# 丰疆中国与海外品牌监测 · 免费静态版

仓库根目录包含可直接部署的静态文件，无需构建、登录或服务器。GitHub Pages 分支 `main` 根目录托管。

## 使用

- **监控日报**：按北京时间每天一份累计报告；显示新增、变化、待核查、来源分布、复核进度和查询覆盖。证据明细默认折叠。
- **线索复核**：一个处理结论和对应依据；页面状态、图形比对为可选事实，不混同授权结论。
- **监控配置**：一个入口内维护品牌与参照图、市场平台、规则、连续执行及每天北京时间 09:00 周期。
- **运行中心**：实际来源状态、查询日志、失败原因、飞书自动同步与群简报和本机 JSON 迁移。

自动与手动检索按同一个北京时间日期累计，规范化页面链接去重。检索后生成记录，不等待全部复核；待核查与已核查分开显示。每次检索、站点补查、复核产生不可变更新记录，飞书同日子文档持续追加，不替换原报告。跨午夜任务归入开始日期；次日复核追加到次日。可下载当前累计图表与更新链的 HTML（打印 PDF）。优先级不等于侵权认定。日报指标与线索标题可直接打开对应复核范围。

数据保存在本机 IndexedDB，兼容 `fjd-watch-static-v2`；任务独立保存。现有线索、备注、图片与周期设置继续兼容。GitHub 加密云备份界面已移除；既有远端密文未删除。更换设备请用本机 JSON 备份迁移，飞书日报不是完整任务数据库。

无密钥文字检索使用 Tavily 公共访问模式。将实际完全相同的索引请求合并，保留覆盖目标市场与语言。在全部 83 市场、84 平台、现有全部文字名称下，143,346 种组合对应 13,860 条不同请求，减少约 90.3% 重复；不代表已经执行这 13,860 条。各平台轮转，默认每次连续执行 60 条，可选 20/60/120/300；旧的 20 条选择保留。页面关闭、休眠或离线时不执行，每次到期按所设数量继续队列。逐条保存，可暂停后继续。立即更新从队首重查本次额度，不再受最近单条查询影响。

请求间隔 1.2 秒；短时 429 最多冷却重试两次，遵循 Retry-After（较长冷却直接保存进度并暂停）。临时网络/服务器错误重试一次，连续三项失败暂停；身份访问限制仍如实记录。免费通道可能限流，不保证全量或不失败。无命中会尝试简化品牌词补查；严格检查目标域名及正文/标题品牌文字，URL 文字单独出现不保留。

图片参照保留 Excel 70 组、123 张样式及官网图片；图片检索仍需人工在外部图片搜索提交，不声称有自动相似度能力。

## 开发与验证

`npm test` 验证模型逻辑；`npm run preview` 在本机 4180 端口预览。

初始数据：53 条公开线索，其中 49 条曾直接读取原网页核验。每条有来源链接、查询词和复查入口。检索市场与有地址依据的商家所在地分开保存。

市场 / 平台覆盖为 83 个市场、84 个平台与独立站入口；这些是可检索范围，不代表原生 API 已接通。Excel 参照信息见 `brand-catalog.json`，隐藏表未发布。

官方网站素材及语言证据在 `assets/manifest.json` 和 `platform-languages.json` 中记录。

## 飞书日报与免费本机助手

见 [本机助手接入说明](FEISHU_SETUP.md)，下载 [完整运行包](downloads/fjd-feishu-assistant.zip)。Python 3.10+ 标准库实现，无 pip 依赖。保留原网页、存储与检索技术，增加本机文档同步执行端。

- 目标知识库已预填用户指定链接；需要创建企业自建应用、发布并授予知识库和群访问权限。当前仓库不含用户应用密钥，不声称已经接通飞书。
- 本机设置页保存 App Secret 到网页根目录外的 SQLite；网页只保存本机连接码，不包含在 JSON 导出中。
- 默认每天 09:00 网页检索，09:30 助手发送一次群简报。手动补充不反复发群。关闭网页无法执行检索；助手停止、电脑关机或休眠无法同步/发群。
- 事件队列持久化、同步回执、稳定请求编号及远端校验标记支持断线重试；群推送回执不明时停止重发，避免重复刷群。
- 每张网站卡片可单独补查，优先失败/未执行查询，每次最多 5 条，不重置全局进度。监控配置合并定时与立即检索，完整队列作为高级详情。
- 原 Notion 页面和旧兼容代码未删除，网页已改用飞书；原公开补充检索仍按批次只导入一次。

开发验证：`npm test`；`python -m unittest discover -s bridge -p 'test_*.py'`。构建完整助手包：`python scripts/build_assistant.py`。
