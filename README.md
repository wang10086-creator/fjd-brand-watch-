# 丰疆海外品牌监测 · 免费静态版

发布目录为 `public/`，无需构建、登录或服务器。GitHub Pages 分支 `main` 根目录托管。

## 使用

- 线索复核：按链接去重，查看原查询、来源证据及评级依据，保存人工复核。
- 检索任务：国家 / 地区、适用平台全选、分语言查询、分批文字检索、图片参照和页面内定时执行。
- 品牌档案：品牌词、官网原图和本机上传参照图。
- 运行与数据：真实执行日志、失败原因、JSON 备份与 CSV 导出。

状态保存在浏览器 `fjd-watch-static-v2`。旧站 `fjd-watch-v1` 的 JSON 备份可导入。复核记录不发布到公开仓库。公开仓库仅含公开来源线索、官网识别素材和应用代码。

无密钥文字检索通过 Tavily 公共访问模式，可能受到共享限流。查询 Google / Bing 的链接为备用人工入口。图片检索需要在外部搜索引擎中手动提交参照图和处理验证。没有自动图形相似度服务。

定时默认为每天北京时间 09:00、一批 5 条，浏览器关闭或休眠时不执行。到期后重新打开最多补跑一批。查询成功只代表索引响应，不意味着检索完平台所有商品。不会跳过授权商家，线索不构成侵权结论。

## 开发与验证

`npm test` 验证模型逻辑；`npm run preview` 在本机 4180 端口预览。

初始数据：53 条公开线索，其中 49 条曾直接读取原网页核验。每条有来源链接、查询词和复查入口。检索市场与有地址依据的商家所在地分开保存。

官方网站素材及语言证据在 `public/assets/manifest.json` 和 `public/platform-languages.json` 中记录。
