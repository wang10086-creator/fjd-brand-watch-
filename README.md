# 丰疆中国与海外品牌监测 · 免费静态版

仓库根目录包含可直接部署的静态文件，无需构建、登录或服务器。GitHub Pages 分支 `main` 根目录托管。

## 使用

- **监控日报**：按北京时间每天一份累计报告；显示新增、变化、待核查、来源分布、复核进度和查询覆盖。证据明细默认折叠。
- **线索复核**：一个处理结论和对应依据；页面状态、图形比对为可选事实，不混同授权结论。
- **监控配置**：一个入口内维护品牌与参照图、市场平台、规则、连续执行及每天北京时间 09:00 周期。
- **运行中心**：实际来源状态、查询日志、失败原因、Notion 批量归档和本机 JSON 迁移。

自动与手动检索合并到同一天，规范化页面链接去重。检索后就生成草稿，不等待全部复核。单日“导出与 Notion 归档”可生成可视化 HTML（可打印 PDF）或包含同版 HTML 的 Notion 归档包。首次定稿为 v1；数据不变重复导出不增加版本；当日数据或复核变化提示重新定稿，同日更新 Notion 原篇。次日复核不会改写昨日结论。优先级不等于侵权认定。

数据保存在本机 IndexedDB，兼容 `fjd-watch-static-v2`；任务独立保存。现有线索、备注、图片与周期设置继续兼容。GitHub 加密云备份界面已移除；既有远端密文未删除。更换设备请用本机 JSON 备份迁移，Notion 日报不是完整任务数据库。

无密钥文字检索使用 Tavily 公共访问模式。将实际完全相同的索引请求合并，保留覆盖目标市场与语言。在全部 83 市场、84 平台、现有全部文字名称下，143,346 种组合对应 13,860 条不同请求，减少约 90.3% 重复；不代表已经执行这 13,860 条。各平台轮转，默认每次连续执行 60 条，可选 20/60/120/300；旧的 20 条选择保留。页面关闭、休眠或离线时不执行，每次到期按所设数量继续队列。逐条保存，可暂停后继续。立即更新从队首重查本次额度，不再受最近单条查询影响。

请求间隔 1.2 秒；短时 429 最多冷却重试两次，遵循 Retry-After（较长冷却直接保存进度并暂停）。临时网络/服务器错误重试一次，连续三项失败暂停；身份访问限制仍如实记录。免费通道可能限流，不保证全量或不失败。无命中会尝试简化品牌词补查；严格检查目标域名及正文/标题品牌文字，URL 文字单独出现不保留。

图片参照保留 Excel 70 组、123 张样式及官网图片；图片检索仍需人工在外部图片搜索提交，不声称有自动相似度能力。

## 开发与验证

`npm test` 验证模型逻辑；`npm run preview` 在本机 4180 端口预览。

初始数据：53 条公开线索，其中 49 条曾直接读取原网页核验。每条有来源链接、查询词和复查入口。检索市场与有地址依据的商家所在地分开保存。

市场 / 平台覆盖为 83 个市场、84 个平台与独立站入口；这些是可检索范围，不代表原生 API 已接通。Excel 参照信息见 `brand-catalog.json`，隐藏表未发布。

官方网站素材及语言证据在 `assets/manifest.json` 和 `platform-languages.json` 中记录。

## 增量监控与附件参考

新增 `monitor.js` 事件台账和 `daily-view.js` 日报界面，保留既有检索与存储技术。旧线索只作为底库，不反推历史新增；旧复核备注保留。

重点网址可按批次持续复查，索引未命中不表示下架。人工复核限于具体页面；新信号提示重查。证据索引包含可复算的 SHA-256，不冒充完整网页截图。

## Notion 日报归档

[私有日报总页](https://app.notion.com/p/3f865b803b2b81cf800bff7fcf1624db) 已保存 2026-10-13 公共补充检索子笔记。网页“监控日报”统一导出单日汇报与 Notion 归档包；“运行中心”可批量导出历史。归档包包含 HTML 图表，上传至当前对话后通过连接写入 Notion，同日更新原笔记。用户本机历史尚需提供，当前不承诺自动后台同步。`public-scan.json` 为实际执行的中国公开检索记录，启动时按批次 ID 导入一次；不冒充本机执行或商品首次上架。
