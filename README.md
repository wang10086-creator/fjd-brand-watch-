# 丰疆海外品牌监测 · 免费静态版

仓库根目录包含可直接部署的静态文件，无需构建、登录或服务器。GitHub Pages 分支 `main` 根目录托管。

## 使用

- 监控日报：按北京时间选择日期、近七日增量图，首次 / 变化 / 重复 / 人工复核分开统计，导出独立 HTML 日报。
- 线索复核：按链接去重，查看原查询、来源证据及评级依据，保存人工复核。
- 检索任务：国家 / 地区、适用平台全选、平台支持语言＋地区语言＋英语、立即更新、分批文字检索和页面内定时执行。
- 品牌档案：品牌词、Excel 70 个参照组 / 123 张原图、官网及本机上传参照图。
- 运行与数据：实际状态指示灯、站点查询覆盖、失败原因、加密 GitHub 备份和 CSV 导出。

状态优先保存在本机 IndexedDB，兼容备份仍写入 `fjd-watch-static-v2`；任务另存独立小型日志，输入即时保存。旧站 `fjd-watch-v1` 的 JSON 备份可导入。主分支含公开来源线索、官网及用户提供的可见商标参考素材和应用代码，不含个人复核记录。

完整数据可在“运行与数据”设置密码后加密备份至 GitHub `data-backups` 分支。无需费用的方式为下载密文并在 GitHub 网页上传提交；可选的一键同步需用户在当前页面提供仅该仓库 Contents 读写权限的凭据。密码和凭据不写入本机存储或备份。恢复时需要原密码；关闭网页不会自动同步。

无密钥文字检索通过 Tavily 公共访问模式，可能受到共享限流。查询 Google / Bing 的链接为备用人工入口。图片检索需要在外部搜索引擎中手动提交参照图和处理验证。没有自动图形相似度服务。

定时默认为每天北京时间 09:00、一批 5 条，浏览器关闭或休眠时不执行。到期后重新打开最多补跑一批。查询成功只代表索引响应，不意味着检索完平台所有商品。不会跳过授权商家，线索不构成侵权结论。

## 开发与验证

`npm test` 验证模型逻辑；`npm run preview` 在本机 4180 端口预览。

初始数据：53 条公开线索，其中 49 条曾直接读取原网页核验。每条有来源链接、查询词和复查入口。检索市场与有地址依据的商家所在地分开保存。

市场 / 平台覆盖为 82 个市场、66 个平台与独立站入口；这些是可检索范围，不代表原生 API 已接通。Excel 参照信息见 `brand-catalog.json`，隐藏表未发布。

官方网站素材及语言证据在 `assets/manifest.json` 和 `platform-languages.json` 中记录。
